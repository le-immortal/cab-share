# Cab Share

A cab-sharing platform for verified employees of pre-approved partner
companies — post a trip, search for one, request to join, chat, and split
the fare offline.

**Status:** spec finalized, implementation not started yet.

Full specification: [docs/SPEC.md](docs/SPEC.md)

## Planned stack

Node.js/TypeScript across the board:
- `apps/web` — React website
- `apps/bot` — Microsoft Teams bot (Bot Framework SDK)
- `apps/api` — shared backend REST API
- `packages/shared` — shared types

See [docs/SPEC.md](docs/SPEC.md) for the full product and technical spec.
